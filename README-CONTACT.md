# Contact Form Setup Guide

This document explains how to set up the contact form to work with Gmail.

## Environment Variables

The contact form uses Gmail to send emails. You need to set up the following environment variables in your `.env.local` file:

```
GMAIL_USER=your-email@gmail.com
GMAIL_PASS=your-app-password
```

## Getting a Gmail App Password

For security reasons, Google requires you to use an App Password instead of your regular Gmail password. Here's how to get one:

1. Make sure you have 2-Factor Authentication enabled on your Google account
2. Go to [Google App Passwords](https://myaccount.google.com/apppasswords)
3. Log in with your Google account
4. Select "App" and choose "Other (Custom name)"
5. Enter a name for your app (e.g., "Next.js Contact Form")
6. Click "Generate"
7. Copy the 16-character password generated by Google
8. Paste this password as the value for `GMAIL_PASS` in your `.env.local` file

## Security Measures

The API route includes security measures to prevent unauthorized use:

- Domain restriction: Only requests from specific domains are allowed
- Input validation: All form inputs are validated on both client and server side
- Error handling: Comprehensive error handling for all edge cases

## How It Works

1. User fills out the contact form on the website
2. Client-side validation ensures all fields are properly filled
3. Form data is sent to the `/api/contact` endpoint
4. Server validates the request origin and form data
5. If valid, an email is sent using Gmail SMTP
6. User receives a success or error message via toast notification
